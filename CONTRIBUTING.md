# Contributing to wOS

First of all, thank you for even glancing at this mess of a build.

This is a one-person hobby OS project — built purely for learning, fun, and the thrill of seeing a disk spin because *I told it to*. If you find bugs, typos, or you’re brave enough to help patch low-level chaos, feel free to open an Issue or a pull request. Any contribution, big or small, is welcome.

**Guidelines:**
- Be respectful. (You probably are — I trust you.)
- Keep it fun. The OS is serious under the hood, but the vibe is not.
- Test changes in a VM first. Canary builds love eating real machines.
- If you break something, help fix it too. 😆

I built the whole thing, brick by brick — with datasheets, cries, and hair pulled out of my scalp.

**P.S.** Please please please don’t fail me. I love you, Professor!
